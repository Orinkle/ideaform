五段变奏（**不换曲，只换形态**）：

| 段 | 模板 | 层 | 力度 | 动机 | 相对上段变了什么 |
|---|---|---|---|---|---|
| S1 | present 呈现 | pad | p (62) | 原形（唯一一次陈述） | —（建立身份） |
| S2 | develop 展开 | pad+bass+lead | mp (78) | 模进 | 层数/密度/力度/和声 |

### ③ 变奏计划 → LMMS 工程 → BGM 音轨

`out/bgm-plan.json` → `out/bgm.mmp` → `out/bgm.wav`

由 `bgm-from-plan.py` 把计划翻成 `.mmp`（7 轨：Pad/Lead/Counter/Pluck/Bass/Kick/Hat）。
音高素材只有一个动机细胞 **`[0,3,7]`**（小三和弦），五段全靠变形与配器撑开。

分轨实测 RMS（dBFS）：

| 段 | RMS | 峰值 | Δ vs 上段 |
|---|---|---|---|
| S1 呈现 | **−24.29** | −6.86 | — |
| S2 展开 | **−23.58** | −3.15 | +0.71 |
| S3 强调 | **−18.40** | −0.42 | **+5.18** |
| S4 对照 | **−30.46** | −6.69 | **−12.06** |
| S5 收束 | **−25.58** | −6.37 | +4.88 |

整轨 RMS −22.50 dBFS、峰值 **−1.02 dBFS**、**削顶样本 0**。

重音点实测（前后各 1.2 s 窗口 RMS 差）：**+6.83 / +4.08 / +10.53 / +11.00 / +3.50 / +4.30 dB**
→ "留白后抬力"在波形里听得出来，不是纸面设计。

> **踩坑（连踩两次，记牢）**：主音量 `0.30` 时峰值顶到 0 dBFS、**1306 个削顶样本**；
> 降到 `0.22` 仍剩 23 个；降到 **`0.18`** 才真正干净（0 削顶、峰值 −1.02 dBFS）。
> 生成器因此加了 `--master` 参数，并把"渲染后必须实测峰值"写进帮助文本。
> 另一坑：段落边界各自 `ceil/floor` 向内收会**漏出空小节**（bar 6/11/25/38 全无音符），
> 导致重音点落在空小节里、留白无从谈起 —— 改成各段小节区间首尾相接，并加了空小节自检。

### ④ 混音 + 成片

音量由**实测 RMS 反推**，不是拍脑袋：

```
旁白 RMS −24.36 dBFS，BGM RMS −22.50 dBFS，目标"BGM 低于旁白 9 dB"
gain = (−24.36 − 9) − (−22.50) = −15.40 dB  →  volume = 10^(−15.40/20) = 0.2862
```

## 2. 复现命令（本目录内）

```bash
# ① 渲染成片（自带音轨，路线 A）
cd remotion
export TMPDIR=<工作空间>/.tmp/tmpdir
export VW_CHROME=<契约 tools.remotion.browser.resolved>
npx --no-install remotion render IntroWithAudio ../../final.mp4 --concurrency=2

# ② 渲染封面
npx --no-install remotion still Cover ../../cover.png

# ③ 无目视校验（退出码 0 = 全过）
cd ../..
python3 ../../skills/ideaform/scripts/verify-video.py video final.mp4 --frames 3797 --fps 30
python3 ../../skills/ideaform/scripts/verify-video.py cover cover.png --layout cover
```

`remotion/node_modules` 不入库：在 `remotion/` 下 `npm install`，
或软链到本机任一已装好依赖的 Remotion 工程（`ln -s <已有工程>/node_modules node_modules`，避免重复装包）。
`VW_CHROME` 必须指到**实际存在**的 chrome —— 写死路径的 `remotion.config.ts`
换机器就会变成死路径（本项目的模板因此刻意走环境变量）。

## 3. 画面：五层视觉语言 + 两件新装置

层次与 BGM 五段变奏**严格同源**（帧号来自 `timeline.ts`，小节号来自 `bgm-plan.json`）：

| 层 | 帧区间 | BGM 段 | 形态变化 |
|---|---|---|---|
| 01 问题 | 15–458 | S1 present | 纸底、无栅格、1 条能量条 |
| 02 四件套 | 458–848 | S2 develop | 淡栅格、2 条能量条 |
| 03 逐站展开 | 848–1899 | S3 intensify | **整屏反相**（墨底纸字）、栅格 0.22、5 条能量条（末条红） |
| 04 编排 | 1899–2931 | S4 contrast | 回到纸底、栅格最稀、1 条能量条（呼应音乐的大幅收薄） |
| 05 收束 | 2931–3797 | S5 resolve | 纸底、2 条能量条 |

**新增装置 ① 流水线导轨**（底部）：`01 文稿 → 02 声音 → 03 画面 → 04 音乐 → 05 成片`，
当前工位红、已过墨、未到描边。工位起止帧直接取自 `CUES`，解说走到哪一站导轨就亮到哪。

**新增装置 ② 工具铭牌**（右侧）：当前工位的工具名 + 一行原理 ——
`AI 大模型`（展开成分层解说稿）/ `edge-tts`（Edge 朗读服务，在线神经语音，无需密钥）/
`Remotion`（React 描述画面，无头浏览器逐帧渲染）/ `LMMS`（开源 DAW，照时间轴写小曲）/
`ffmpeg`（音视频封装）；第 5 层换成 ideaform 自己的铭牌（编排者）。

**重音的视觉同步**：六处重音点，左缘红条脉冲 + 层标签转红 + 力度计涨一档 + 当前节点红环。

对角轴恒定走在**文字块下方**（`y1=1.12H → y2=0.52H`）；导轨标签带底色芯片，
保证轴线不切进文字。层次切换用**几何扫过块**过渡，不用淡入淡出。

> 画面与音乐用的是**同一套思路**：保持身份（纸底/墨色/红/网格/对角轴）不变，
> 只变形态（反相/栅格密度/能量条数）。视觉的"变奏"与听觉的"变奏"在时间上对齐。
