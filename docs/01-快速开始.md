# 01 · 快速开始

> 目标：**从 clone 到跑通第一个视频**，中间不需要人工配置工具链。

---

## 步骤 0 · 把仓库交给 Agent

把这个仓库（或它的路径）交给 Agent，说：

> 用 `skills/ideaform-setup` 把环境配好，然后用
> `skills/ideaform` 给我做一条视频。

Agent 会按下面的顺序自动推进。你也可以手动逐步执行。

---

## 步骤 2 · 补装缺失项（会先问你）

```bash
bash skills/ideaform-setup/scripts/install.sh --dry-run   # 先看会做什么
bash skills/ideaform-setup/scripts/install.sh             # 逐项确认后执行
bash skills/ideaform-setup/scripts/install.sh --only lmms # 只装某一项
```

- 装之前会把**将被覆盖的已有文件**备份到 `~/.config/ideaform/backup/<时间戳>/`
- 每完成一步就向 `install-manifest.jsonl` 追加一条（append-only，供回滚）
- 全部落**用户级路径**，不需要 root

---

## 步骤 3 · 写契约

```bash
python3 skills/ideaform-setup/scripts/detect.py --write
```

产出：

```
~/.config/ideaform/
├── toolchain.json     ★ 路径契约（两个 Skill 之间的唯一接口）
├── env.sh             可直接 source 的导出脚本
├── install-manifest.jsonl
├── backup/
└── logs/
```

此时 `verified_at` 还是 `null`。可以 source 一下验证：

```bash
source ~/.config/ideaform/env.sh
echo "$VW_LMMS_APPRUN"        # → .../squashfs-root/AppRun
vw tools.remotion.version     # → 4.0.515
```

## 步骤 4 · 收割社区 Skill（拿来主义）

```bash
python3 skills/ideaform-setup/scripts/harvest-skills.py --from-contract
```

按契约给链上每个工具去 GitHub 找现成的成熟 skill：评分（stars/许可证/新鲜度）→
安全扫描 → 落盘 `~/.workbuddy/skills/`。命中危险模式的进 `_quarantine/` 隔离区由你定夺；
本地进化过的 skill 有分叉保护，不会被覆盖。**找不到合格候选的工具，才轮到项目自己写 skill。**

以后生产中引入新开源工具（比如化学结构式绘制 → RDKit），同样先跑
`harvest-skills.py <工具名>`，协议见 `skills/ideaform-setup/references/skill-harvest.md`。

## 步骤 5 · 端到端冒烟校验（**必做**）

```bash
python3 skills/ideaform-setup/scripts/verify.py
```

真的跑一遍最小闭环，四项全过才盖章：

> **★ 验收标准**：再在**零环境变量**下重跑一次 ——
> `env -u TMPDIR -u VW_TMPDIR -u VW_CHROME python3 skills/ideaform-setup/scripts/verify.py`
> 仍全过，才说明契约自洽（工具链 / TMPDIR / chrome 路径全部从契约里读到）。
> 靠手动 `export` 才过 = 契约有漏。

| 检查 | 实测判据（本机样例） |
|---|---|
| ① TTS | 合成一句中文 → 36 KB，一次成功 |
| ② 画面 | Remotion 渲 1 帧 → 1920×1080 PNG，1.1 MB |
| ③ 音频渲染 | LMMS 渲 1 个小工程 → 峰值 0.81 FS，RMS 4607，4.0s |
| ④ 音视频合流 | 造静音轨陷阱 + `-map` 合流 → 音轨 189263 bps |

通过后 `verified_at` 被盖进 `toolchain.json`。

**有不过的项 → 先修，别盖章，也别删环境配置技能。**

## 步骤 6 · 收尾：让 Agent 问你三选一

环境配好后，Agent 会汇报并让你选：

| 档 | 做什么 | 可逆性 |
|---|---|---|
| **A. 禁用**（推荐） | frontmatter 置 `disable: true` | 改回 `false` 即恢复 |
| **B. 归档** | 移到 `$VW_CONFIG_ROOT/archive/` | 移回来即恢复 |
| **C. 删除** | 真删目录（先自动备份） | 用备份恢复 |

无论哪档都**先备份再动手**。详见 [`04-安全与回滚.md`](04-安全与回滚.md)。

**关键点：契约文件在 Skill 目录之外，所以禁用/删除环境配置技能后，工作流技能照常工作。**

## 步骤 7 · 生产视频

```bash
# 契约继续生效
source ~/.config/ideaform/env.sh

# ① 文稿 → 分层 script.md + 台词.txt
# ② TTS 定轴
"$VW_VENV/bin/python" skills/ideaform/scripts/make-tts-track.py \
    --lines 台词.txt --fps 30 --audio \
    --plan-out out/plan.json --ts-out out/timeline.ts

# ③ BGM 变奏
"$VW_VENV/bin/python" skills/ideaform/scripts/bgm-plan.py \
    --plan out/plan.json --layers "1:present,4:develop,6:resolve" \
    --out out/bgm-plan.json
#    → 按 bgm-plan.json 出 .mmp 并渲染 bgm.wav

# ④ 画面 + 音轨集成 + 封面 + 校验
```

完整流程见 [`02-工作流总览.md`](02-工作流总览.md)。

## 换个工作空间怎么办？

契约是**机器级**的（同一台机器上路径不变），所以换工作空间不用重配。

```bash
export VW_CONTRACT=~/.config/ideaform/toolchain.json
```

只有当**工具位置变了**（重装 LMMS、换 Node 版本）才需要：

```bash
python3 skills/ideaform-setup/scripts/detect.py --write   # 刷新契约
python3 skills/ideaform-setup/scripts/verify.py           # 重新盖章
```

## 常见第一坑

| 现象 | 原因 | 处理 |
|---|---|---|
| Remotion 报 `browserExecutable ... does not exist` | 工程里写死了旧的 chrome 路径 | 重跑 `detect.py --write`；契约会给 `browser.resolved` |
| 任何步骤报 `ENOSPC` | `/tmp` 只有 10MB | `source env.sh`（会设 `TMPDIR`），或显式 `export TMPDIR=$VW_TMPDIR` |
| LMMS 渲染全程静音、日志无报错 | `stkdir` 不对 | 看 `detect.py` 报告的 `stkdir` 行；跑 `install.sh --only lmms` |
| TTS 报 403 / `HandshakeError` | edge-tts 版本太老 | `"$VW_VENV/bin/pip" install -U "edge-tts>=7.3.1"` |
| 中文渲染成方框 | 字体族名没写全 | 用 `"Noto Sans CJK SC Black"`，先 `fc-match` 确认 |
